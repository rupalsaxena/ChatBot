# Griot ChatBot

Griot is a ChatBot build for Advanced Topic of AI coursework of Univeristy of Zurich. 

It can very well answer four types of questions:

FACTUAL QUESTIONS: Who is director of The Bridge on the River Kwai?

EMBEDDING QUESTIONS: Who is screenwriter of The Masked Gang: Cyprus?

MULTIMEDIA QUESTIONS: Show me a picture of Halle Berry.

RECOMMENDATION QUESTIONS: Recommend movies similar to Hamlet and Othello. 

To run the pipeline of the code with speakeasy, run the following:
```
cd src
python3 run_bot.py
```

In order to test the pipeline without connecting it to speakeasy, do the following:
```
cd src
python3 main.py
```
